## 확정된 결정
- 목적: 기법별 국장·미장 각 최대 3종목 스크리닝(없으면 "현재 적격 종목 없음") + 사후 수익률 통계. 표기 "스크리닝 결과(통계용)", 매수·매도 권유 금지
- 사용자는 **스윙**(며칠~몇 주 보유) 목적
- 기법 진행 3개: 미너비니 SEPA · 워렌 버핏(경제적 해자) · 조지 소로스(재귀성). 볼린저밴드 **보류**(명세만 유지). "기술적 분석"은 삭제
- 판단 = Claude(판정·근거), 판단 근거 팩트체크 = Gemini(확인·불일치·확인 불가 + 출처, 판정 안 함). 숫자 근거는 코드가 대조. 불일치면 그 근거 빼고 Claude 재판단(상향 금지)
- 숫자는 코드만 계산(LLM이 숫자 생성 금지). 실행 1회 비용 상한(임시 $2, 시험 실행 후 확정)
- 실행은 요청 시에만. 체크박스 실행 폼은 기각 → 요청 방법 미정(Q40). 모든 방법은 같은 요청 JSON으로 워크플로 호출
- 범위 기본값 국장 전체·미장 전체, 여러 범위 선택 가능, 공식 구성종목 못 받으면 ETF 근사
- '실적' = **주가 수익률**(경영실적 아님): 선정일 기준가(추천 직전 종가) → 확인 시점 가격
- 가격 = **전날(최근 거래일) 종가**, 정확해야 함. 화면을 볼 때마다 갱신(최신 종가 있으면 조회 없이 표시). 분할·무상증자 보정 필수(AC38)
- 화면: 첫 화면 **카드형**(회사명 · 회사정보[사업의 개요·실적] · 선정근거), 수익률 화면은 **종목 리스트**(그래프 없음)
- 구글 파이낸스: 공식 API 없음·최대 20분 지연 → 쓰지 않음
