## 작업 방법 메모 (중요)
- **실행 위치**: 이 클라우드 세션은 야후·SEC 등 데이터 사이트 접속이 정책으로 막혀 있다(우회 금지). 그래서 실제 데이터 시험은 GitHub Actions에서 돌린다. 실행 상태는 공개 API(`api.github.com`, 인증 없이)로 확인할 수 있다
- **워크플로 실행**: 수동 실행(workflow_dispatch)은 기본 브랜치(main)에 있는 워크플로만 된다(API 404). 그래서 test 브랜치 워크플로는 push로 돌린다
  - `r1000x-experiment`: 그 워크플로 파일 자체를 고쳐 푸시하면 실행
  - `backtest-experiment`(S&P 500): 지금은 수동 실행만 있어 사실상 안 돈다 → 다시 돌리려면 자기 파일 경로를 push 조건으로 넣는다(그 푸시가 곧 실행)
  - `reddit-analyze`: `experiments/reddit/**` 푸시 · `weekly-osc`: `experiments/weekly/**` 푸시 · `reddit-experiment`(수집): 수동 실행만
