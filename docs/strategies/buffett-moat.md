# 기법 스펙 — 워렌 버핏 (경제적 해자 중심, v0.2)

> 결과는 "스크리닝 결과(통계용)"이며 투자 권유가 아니다.
> 버핏은 숫자 컷오프를 공개한 적이 없다. 아래 숫자 기준은 **AAII의 Buffett-Hagstrom 스크린(출처 있음)** 또는 **제안(출처 없음)**으로 구분한다.
> 일부 출처는 원문 접속이 차단되어 검색 결과 요약으로 확인했다(†).

## 1. 기법 정의 (출처)
| 원칙 | 내용 | 출처 |
|---|---|---|
| 해자의 지속성 | "투자의 핵심은 산업 성장성이 아니라 기업의 경쟁우위, 무엇보다 그 우위의 **지속성**을 판단하는 것" | Buffett, Fortune 1999 — [Motley Fool](https://www.fool.com/investing/general/2008/04/24/i-like-big-moats-and-i-cannot-lie.aspx)† |
| 인수 기준 (일부) | 입증된 일관된 이익창출력(미래 전망·턴어라운드 제외), 부채 거의 없이 높은 ROE, 단순한 사업 | [Berkshire 연차보고서 인수 기준](https://www.berkshirehathaway.com/2001ar/acq.html)† |
| 12가지 원칙 | 사업(단순·일관된 실적·장기 전망) / 경영(합리성·솔직함·관행 추종 거부) / 재무(EPS보다 ROE, 오너 이익, 높은 이익률, 유보 1달러당 시가 1달러 이상) / 시장(가치 산정, 큰 할인 매수) | R. Hagstrom, *The Warren Buffett Way* — [Old School Value 요약](https://www.oldschoolvalue.com/?p=22771)† |

## 2. 평가 순서 (종목 선정용으로 재구성)
① 해자의 숫자 흔적(코드) → ② 자본배분(코드) → ③ 해자 원천·지속성(LLM) → ④ 가격·안전마진(코드 값 + LLM) → ⑤ 판정

## 3. 1차 필터 (코드가 판단)
| # | 조건 | 근거 |
|---|---|---|
| 1 | 영업이익: 최근 12개월 + 최근 7개 회계연도 모두 흑자 | AAII 스크린 (일관된 이익창출력) |
| 2 | ROE: 현재 > 15%, 최근 3개 회계연도 각각 > 15% | AAII 스크린 |
| 3 | 부채비율(D/E): 업종 중앙값보다 낮음 | AAII 스크린 ("부채 거의 없이") |
| 4 | 영업이익률·순이익률: 각각 업종 중앙값 초과 | AAII 스크린 ("높은 이익률") |
| 5 | 1달러 테스트: 5년 시가총액 증가분 ≥ 5년 누적 유보이익 | Buffett 원칙 (AAII는 "5년 주가 변화 > 장부가 변화"로 근사) |
| 6 | 오너 이익 근사치(영업현금흐름 − 자본지출) 최근 연도 > 0 | 제안 — 유지 capex 분리 불가로 FCF로 대체 |
| 7 | 시가총액: 미장 ≥ $10억 / 국장 미결 | AAII 스크린(미장) |
- **후보 정렬:** "주가/FCF ÷ FCF 성장률"이 낮은 순으로 시장별 N개를 LLM에 전달 (AAII는 하위 30개 채택)
- **금융업:** 부채·이익률 지표 체계가 달라 별도 처리 필요 (PRD 미결)

## 4. LLM 판단 기준
- **해자 원천:** 5가지 중 무엇인지 + 제공 자료 안의 근거. 근거가 없으면 "미확인"
- **지속성:** 우위를 위협하는 요인(규제·기술 변화·신규 진입). 지속성이 불분명하면 적격 불가
- **숫자와 일관성:** 주장한 해자 원천이 ROE·이익률 안정성과 맞는지
- **사업 이해 가능성:** 제공 자료만으로 사업모델 설명이 가능한지 (Berkshire "단순한 사업"의 앱 해석)
- **자본배분:** 1달러 테스트, 증자·자사주 흐름 (자료 없으면 "미확인")
- **가격:** 코드가 준 FCF 수익률·PER의 과거 대비 위치로만 판단. **내재가치 숫자를 지어내지 않는다**
- **판정:**
  - 적격: 해자 확인 + 숫자 일관 + 가격 합리적
  - 관찰: 좋은 기업이나 가격 부담
  - 제외: 그 외
- **개수:** 시장별 최대 3개. 미달이면 있는 만큼, 0개면 "현재 적격 종목 없음". 관찰을 적격으로 올려 채우지 않는다
