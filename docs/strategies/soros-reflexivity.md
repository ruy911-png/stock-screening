# 기법 스펙 — 조지 소로스 (재귀성, 종목 선정용 v0.2)

> 결과는 "스크리닝 결과(통계용)"이며 투자 권유가 아니다.
> 소로스는 숫자 스크리닝 규칙을 남기지 않았다(재량 판단). 아래 **개념은 출처 있음**, **숫자 기준은 전부 제안**이다.
> 범위 밖: 공매도, 시장 타이밍(현금 대기), 시장 전체 국면 예측.
> 일부 출처는 원문 접속이 차단되어 검색 결과 요약으로 확인했다(†).

## 2. 종목 선정 적용 (재구성)
**목표:** 가격 상승과 실적 개선이 **서로를 강화하는 초기 국면**(가속 ~ 시험 통과)의 종목을 찾고, 황혼·반전 국면 종목은 거른다.

| 단계 | 판정 | 앱에서의 의미 |
|---|---|---|
| 가속 | 적격 후보 | 주가 상승 + 실적 개선이 동시에 진행 |
| 시험 통과 | 적격 후보 (가점) | 의미 있는 조정 후 회복해 추세 유지 |
| 진실의 순간 근접 | 관찰 | 기대(주가·밸류에이션 상승) 대비 실적이 따라가지 못하기 시작 |
| 황혼 | 제외 | 주가는 버티지만 실적 둔화가 이어짐 |
| 반전·붕괴 | 제외 | 추세 훼손 |

## 3. 1차 필터 (코드가 판단) — 전부 제안
| # | 조건 | 의미 |
|---|---|---|
| 1 | 유동성 하한 (PRD 미결) | 공통 |
| 2 | 6개월 수익률 시장 상위 20% + 종가 > 200일선 | 지배적 추세 존재 |
| 3 | 최근 분기 매출 또는 영업이익 YoY 증가, 직전 분기보다 감속하지 않음 | 추세가 실적과 동반 (가격만의 상승 배제) |
| 4 | 최근 12개월 내 −10% 이상 조정 후 52주 고점 대비 −10% 이내로 회복 | 시험 통과 (가점, 필수 아님) |
| 5 | 실적 2분기 연속 감속 + 주가 신고가 → 제외 / 52주 고점 대비 −25% 초과 하락 → 제외 | 황혼·반전 배제 |

- **2번 근거:** 과거 6개월 수익률 기준 정렬 시 이후 1년 수익률 차이가 컸고, 가격·이익 모멘텀이 함께 작동한다는 연구가 있다 (Chan·Jegadeesh·Lakonishok 1996 — [CFA Digest 요약](https://rpc.cfainstitute.org/research/cfa-digest/1997/08/momentum-strategies-digest-summary)†). 소로스 원전 규칙이 아니라 **앱 운용용 근사**다.
- **후보 정렬:** 2번 수익률 순위 + 3번 실적 가속 정도 → 시장별 N개를 LLM에 전달

## 4. LLM 판단 기준
- **추세와 편향 분리:** 실제 개선(숫자)과 시장의 기대·내러티브를 각각 한 줄로 쓴다. 내러티브는 판단 근거가 아니라 분석 대상
- **재귀 경로:** 주가가 실적을 강화하는 경로(증자·주식 인수·차입·인재)가 제공 자료로 확인되는가. 없으면 "미확인" (적격 불가 아님, 감점)
- **단계 판정:** 2장 표 기준. 가속·시험 통과만 적격
- **괴리:** 주가·밸류에이션 상승폭 vs 이익 증가폭. 괴리가 과도하면 관찰
- **판정:** 적격 / 관찰 / 제외
- **개수:** 시장별 최대 3개. 미달이면 있는 만큼, 0개면 "현재 적격 종목 없음". 관찰을 적격으로 올려 채우지 않는다

## 6. 사용자 인계 문서와의 관계
- 반영: 재귀성 개념, 내러티브와 숫자 분리, 조기 역추세 금지
- 제외 (범위 밖): 공매도, 현금 대기, 시장 전체 버블 진단(CAPE·신용잔고·공포지수), 플래시 크래시 모델링
