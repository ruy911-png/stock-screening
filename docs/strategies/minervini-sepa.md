## 1. 기법 정의(출처)
- **SEPA(Specific Entry Point Analysis)**: 미너비니의 종목 선정·진입 시점 분석 방법론. 실적 성장 + 추세(Trend Template) + 변동성 수축 패턴(VCP)·피벗 + 손절 기반 위험관리를 결합한다. 출처: Mark Minervini, *Trade Like a Stock Market Wizard* (McGraw-Hill, 2013, ISBN 9780071807227) — 출판사 소개문에 SEPA 명시([도서 소개](https://www.porchlightbooks.com/products/trade-like-a-stock-market-wizard-mark-minervini-9780071807227)).
- **Trend Template**: 이동평균·52주 고저·상대강도(RS)로 상승추세를 확인하는 조건 묶음. **VCP**: 베이스 안에서 조정 폭과 변동성이 단계적으로 줄어드는 패턴(같은 책 10장 "Mastering the Volatility Contraction Pattern"). 둘 다 같은 책이 출처이나 세부는 2차 출처로만 확인 — 원문 대조 **미확인** (예: [TradingView 스크립트 설명](https://kr.tradingview.com/script/88aL78Qh-TwP-Mark-Minervini-Trend-Template-Criteria)).
- 목표: 실적·추세가 강하고, 진입 위험이 구조적으로 제한되며, 현실적 상승여력이 충분한 종목을 고른다.
- 원칙
  1. 종목 선정(관심 대상)과 BUY CANDIDATE 판정을 분리한다.
  2. 좋은 회사보다 좋은 진입 — 실적이 좋거나 신고가여도 진입 검증(④~⑧)을 생략하지 않는다.
  3. 52주 신고가 근접만으로는 진입 근거가 아니다.
  4. "VCP 가능(형성 중)"과 "VCP 완성"을 구분한다.
  5. 확인할 수 없는 실적·가격·차트·수급은 추정하지 않고 "미확인"으로 둔다.
  6. 개수를 채우려고 기준을 완화하지 않는다.

## 2. 평가 순서 (필수)
판단과 기록은 이 순서를 따른다. 저장 레코드에도 단계별 결과(충족/미충족/미확인 + 근거)를 같은 순서로 남긴다.

| 단계 | 판단 주체 | 내용 | BUY CANDIDATE 불가 사유 |
|---|---|---|---|
| ① 시장·가격 | 코드 계산 + LLM | 기준일·종가 기준 명시, 시장 추세·RS, 과열·이상 거래량·대량 거래 하락 | 대량 거래 하락 |
| ② 펀더멘털 | 코드 계산 + LLM | §3.3, §4 ② | 미충족 시 처리 미결(Q25) |
| ③ Trend Template | 코드 | §3.2 | 하나라도 미충족 |
| ④ Base/VCP | 코드 측정 + LLM 판정 | §4 ④ | VCP 아님 · 미완성 |
| ⑤ Pivot | LLM(구조 레벨 중 선택) | §4 ⑤ | 객관적 구조 없음 |
| ⑥ Extension | 코드 | §5 | 추격(확장 과다) |
| ⑦ Technical Stop | LLM(구조 레벨 중 선택) | §4 ⑦ | 손절 불명확 |
| ⑧ Risk/Reward | 코드 | §5 | R/R < 2 |
| ⑨ 최종 판정 | LLM + 코드 검증 | §6, §7 | — |

## 3. 1차 필터 (숫자, 코드가 판단)
기준일 = 실행 시점 직전 거래일(종가 기준, 장중 가격 미사용). MA = N일 종가 단순평균(공통 지표 모듈 `features/technical.py`와 같은 정의).

### 3.1 유니버스 (SEPA 전용)
- 국장 — **사용자 설정값이며 미너비니 원전 규칙이 아니다.**
  - 기본: 시가총액 ≥ 1조원 그리고 20일 평균 거래대금 ≥ 100억원(≥ 200억원 우대)
  - 시가총액 5천억~1조원: 예외 검토 대상 — 앱 처리 방식 미결(Q19)
  - 시가총액 5천억원 미만: 제외
  - 규모 표시: 대형주 ≥ 5조원, 중형주 1조~5조원
- 업종과 무관하게 같은 기준을 적용한다.
- 미장: 국장 기준을 그대로 쓰지 않는다. 기준 미결(Q19) — 확정 전 미장 SEPA 실행 불가.

### 3.2 Trend Template (모두 충족)
1. 종가 > MA50, MA150, MA200
2. MA50 > MA150 > MA200
3. MA200 상승 중 — 판정 기간 미결(Q20)
4. 종가가 52주 저점보다 충분히 높음 — 하한 미결(Q20)
5. 종가 ≥ 52주 고점 × 0.75 (52주 고점 대비 25% 이내)
6. 시장 대비 RS 강함 — 측정 방식·기준값 미결(Q20). 정해지지 않은 기간·컷오프를 임의로 쓰지 않는다.

### 3.3 펀더멘털 (데이터가 있으면 코드 계산 — 필수/선호 여부 미결 Q25)
- 최근 분기 EPS YoY ≥ +25%, 매출 YoY ≥ +20%, 영업이익 증가 (사용자 제공 기준 — 원전 수치와 일치 여부 미확인)
- 최근 2~4개 분기 성장 지속 또는 가속
- 항목별 충족/미충족/미확인을 분기·비교 기준 분기·GAAP/Non-GAAP 구분과 함께 기록

### 3.4 LLM 전달
통과 종목을 정렬(제안: RS 순 → 거래대금 순)해 시장별 상위 N개(PRD Q4)를 전달한다. 순위 가산 요소 — RS 강함, 주도 업종, 유동성, 기관 참여 가능성, 시장 주도력 — 중 코드로 계산할 수 없는 항목은 LLM이 판단한다.

## 4. LLM 판단 기준
LLM은 코드가 준 수치와 **구조 레벨 목록**(가격 + 레벨명: 베이스 상·하단, 수축별 고·저점, 직전 고점, 주요 이평 등)만 근거로 쓴다. Pivot·Stop·Target은 이 목록에서 고르고 근거 레벨명을 적는다.
- **① 시장·가격**: 기준일·종가 기준임을 밝힌다. 시장 지수 추세와 종목 RS, 이평 대비 과열, 이상 거래량, 대량 거래 하락일을 본다. 수급 데이터 없이 기관 매집을 단정하지 않는다.
- **② 펀더멘털**: 가이던스 상향, 핵심 사업의 더 빠른 성장(가산), 구체적 촉매를 본다. 저기저 효과 급증은 감점, 일회성 이익은 반복 성장으로 보지 않음, 턴어라운드는 별도 구분, Non-GAAP으로만 흑자인 적자 기업은 보수적으로 본다. 미충족 항목을 명시한다.
- **④ Base/VCP**
  - 확인 항목: 뚜렷한 베이스, 수축 2회 이상, 수축 폭 감소, 캔들 변동폭 감소, 하락일 거래량 감소, 피벗 부근 타이트, 마지막 수축의 거래량 고갈. 수축별 기간·고점·저점·깊이를 가능한 범위에서 기록한다.
  - VCP가 아닌 경우: 급등 후 첫 눌림, 단순 횡보, 거래량이 늘며 하락, 눌림 폭이 줄지 않음, 넓고 느슨함, 돌파 실패.
  - "VCP 가능"과 "VCP 완성"을 구분해 기록한다. Flat Base·Tight Consolidation·Darvas 등 다른 패턴은 자동 인정하지 않는다(Q21).
- **⑤ Pivot**: 객관적 구조(베이스 상단, 핸들 상단, 마지막 수축 고점, 명확한 저항)에서 정하고 어느 구조인지 밝힌다. Pivot과 Entry(진입 가정가)를 구분한다(Entry 산정 규칙 Q22).
- **⑥ Extension**: 확장 ≥ 약 +5%면 우선순위를 낮추고 추격하지 않는다. 이평 대비 과열이면 대기(WAIT), 급등 뒤에는 새 베이스·미니 VCP를 기다린다(WAIT의 판정 기록 방식 Q23).
- **⑦ Technical Stop**: 구조(마지막 수축 저점, 베이스 저점, 피벗 실패 지점, 주요 지지, 이평 + 구조 이탈)에서 정한다. 순서는 구조 → 손절 → 위험. 3R을 만들려고 손절을 좁히지 않고, 일괄 % 손절을 쓰지 않는다. 손절이 불명확하면 BUY CANDIDATE 불가.
- **⑧ Target**: 직전 고점·저항·현실적 여력에서 정하고 부풀리지 않는다. 신고가 구간이 무한 상승여력을 뜻하지 않는다(위쪽 근거 레벨이 없을 때 처리 Q26).
- **금지**(과거 교훈의 일반 규칙): 실적·신고가를 이유로 진입 검증 생략 · 확장된 종목을 피벗 근처로 표현 · 불명확한 VCP를 완성으로 표현 · 실제 손절 없이 R/R 제시 · 현재가 R/R과 계획 Entry R/R 혼용 · 2R 미만을 개수 채우기로 BUY CANDIDATE 분류 · 근거 공백을 일반적인 회사·테마 설명으로 채움.

## 5. 계산식 (코드만 계산 — LLM 계산값은 쓰지 않음)
| 항목 | 식 |
|---|---|
| Extension(%) | (현재가 ÷ Pivot − 1) × 100, 현재가 = 기준일 종가 |
| Risk/주 | Entry − Stop |
| Risk% | (Entry − Stop) ÷ Entry × 100 |
| Reward | Target − Entry |
| R/R | Reward ÷ Risk/주 |

- R/R 구간: < 2R BUY CANDIDATE 불가 · ≥ 2R 가능 · ≥ 3R 우수 · ≥ 4R 매우 우수
- 현재가 기준 R/R과 돌파 후 Entry 기준 R/R은 별도 필드로 저장하고 섞지 않는다. 2R 판정에 쓸 기준은 Q22.

## 6. 최종 판정 (시장별)
| 판정(원문) | 조건 |
|---|---|
| BUY CANDIDATE | ①~⑧ 모두 충족 — R/R ≥ 2, 기준일 최신 데이터 포함 |
| WATCH | 지켜볼 가치는 있으나 아직 준비되지 않음(예: VCP 형성 중). R/R < 2면 "현재 매수후보 제외" 표기 |
| EXCLUDE | 추세 붕괴, 돌파 실패, 대량 거래 하락, 추격, 손절 불명확, 데이터 부족 |

- 개수: BUY CANDIDATE 최대 3. 적으면 적은 대로, 0이면 "현재 적격 종목 없음". WATCH를 올려 개수를 채우지 않는다.
- 3개를 넘으면 §3.4 순위 가산 요소로 고르고 근거를 기록한다.
- 화면·저장 표기 문구는 Q24(원문 표기가 AC9 금지어와 충돌), WATCH 표시·추적은 Q23.

## 7. 출력 · 코드 검증
- 종목별 저장(PRD F6 공통 필드 외): 판정, ①~⑧ 단계별 결과·근거, 펀더멘털 기록(분기·비교 기준 분기·GAAP/Non-GAAP·미충족 항목), 수축별 기간·고점·저점·깊이, Pivot·Stop·Target과 근거 레벨명, Entry, Extension, Risk·Risk%·R/R(현재가 기준 / Entry 기준 분리), 미확인 항목 목록.
- 코드 검증 — 하나라도 실패하면 BUY CANDIDATE로 저장하지 않는다.
  1. Pivot·Stop·Target이 구조 레벨 목록에 있고 Stop < Entry < Target이다. Stop이 목록에 없으면 EXCLUDE(손절 불명확), Target이 없으면 Q26 결정 전까지 BUY CANDIDATE 불가.
  2. 코드가 다시 계산한 R/R ≥ 2. 미달이면 WATCH + "현재 매수후보 제외".
  3. 마지막 일봉 날짜 = 기준일. 아니면 EXCLUDE(데이터 부족).
  4. BUY CANDIDATE 4개 이상 응답은 거부한다(PRD F5). 개수가 모자라도 재요청·조건 완화로 채우지 않는다.
- 구조 레벨·수축 구간 산출 규칙(스윙 고·저점 판정 등)은 원전에 정량 정의가 없어 architect가 설계 시 제안하고 사용자 확인을 받는다.
