# 기법 스펙 — 기술적 분석 (v0.1)

> 결과는 "스크리닝 결과(통계용)"이며 투자 권유가 아니다. 지표 선택은 미결(PRD Q2, Q16) — 아래는 **제안** 기본안.

## 1. 기법 정의(출처)
가격·거래량 이력에서 계산한 지표로 추세와 모멘텀 상태를 판별한다.
| 지표 | 정의 | 출처 |
|---|---|---|
| 이동평균(MA) 5/20/60/120 | N일 종가 단순평균. 단기>중기>장기 순서면 "정배열" | 일반 기술적 분석 관행(국내 HTS 기본 기간) |
| RSI(14) | 14일 상승폭/하락폭 비율 기반 0~100 모멘텀 지표 | J. Welles Wilder, *New Concepts in Technical Trading Systems* (1978) |
| 거래량 비율 | 당일 거래량 ÷ 20일 평균 거래량 | 일반 관행 |
| 볼린저밴드(20, 2) | 20일 MA ± 2 표준편차 | John Bollinger, *Bollinger on Bollinger Bands* (2001) |

## 2. 1차 필터 (숫자, 코드가 판단) — 제안
기준일 = 추천 시점 직전 거래일 종가 기준. 시장별로 아래를 모두 만족하는 종목을 거래대금 순으로 정렬해 상위 N개(PRD Q4, 제안 30)를 LLM에 전달.
1. 유동성: 20일 평균 거래대금 상위 종목(하한값은 PRD Q11)
2. 데이터 충분: 최소 120거래일 이상 OHLCV 존재
3. 추세(제안: 추세 추종형): 종가 > MA20 > MA60 > MA120
4. 과열 제외: RSI(14) < 70
5. 거래량: 당일 거래량 ≥ 20일 평균 × 1.0 (배수는 제안값)

## 3. LLM 판단 기준
LLM에는 후보별 수치(최근 종가, MA 4종, RSI, 거래량 비율, 볼린저 위치 %b, 최근 20일 등락률)만 전달한다.
- 추세의 일관성(정배열 유지 기간, MA 기울기)
- 모멘텀과 과열 사이의 균형(RSI, 볼린저 상단 근접도)
- 거래량이 추세를 뒷받침하는지
- 출력: 시장별 최대 3종목(0~3, 미달 시 있는 만큼, 0개면 "현재 적격 종목 없음") + 종목별 1~3문장 사유(도구가 준 수치만 근거, 권유 표현 금지)
