## 종목 성향 블랙리스트 시범판 (2026-10-06 기준)

## 실제 확인 결과

- NAVER 일봉 원본 12종목 수집 성공. 수집 시각 2026-10-07, 완성 일봉은 2026-10-06까지 사용했다.
- 2024-01-02~2026-10-06의 적격 종목·거래일 7,891개 중 모양 후보 972개(12.32%). 표본은 전력기기·대형주·변동성 종목을 고른 편의표본으로, 국내 전체 시장의 발생률이 아니다.
- 효성중공업 2026-07-16, 09-02, 09-30 일봉을 직접 그려 긴 윗꼬리를 시각 확인했다. 고점→종가는 각각 -5.94%, -4.66%, -1.87%. 같은 모양이어도 급락 크기는 다르다.
- 첨부 화면 고가 2,907,000원과 정확히 같은 고가는 수집 원본에서 발견되지 않았다. 10월 7일 미완성 봉의 고가는 2,888,000원으로 달라, 첨부 사진의 날짜·시장·세션 일치를 확정하지 않았다.

## 모양 정의

윗꼬리 = 고가 - max(시가, 종가), 몸통 = abs(종가 - 시가), 전체 길이 = 고가 - 저가.
일차 검색값은 윗꼬리/전체 ≥ 50%, 몸통/전체 ≤ 35%, 종가가 전체 범위의 아래 40% 이내다. 사용자 확정값이 아닌 모양 검색용 초깃값이며, 캔들 그림과 함께 검수한다. +3%·-5%는 필수조건이 아니다. 작은 가격 변동에서도 같은 형태가 생기므로 모든 후보를 큰 급락이라 부르지 않는다. 장대음봉은 별도의 형태다. 앞선 상승 추세 여부도 모양 자체와 구분해야 한다.

## 전일 정보만 사용한 첫 경고 시험

수집 전에 규칙을 고정했다. 학습한 모델이나 확률 예측기가 아니라 가격·거래량 기준선이며, 하루 한 종목당 한 경고로 평가한다. 그날 완성되는 윗꼬리를 그날의 사전경고에 넣지 않았다.

| 전일까지의 조건 | 경고 수 | 적중 수 | 모양 포착률 | 경고 정확도 | 경고 중 오경보 비중 |
|---|---:|---:|---:|---:|---:|
| 5거래일 수익률 ≥ 10% | 1,044 | 126 | 12.96% | 12.07% | 87.93% |
| 위 조건 + 전일 거래량/그 이전 20일 평균 ≥ 1.5 | 363 | 43 | 4.42% | 11.85% | 88.15% |
| 전일 종가/20일 평균 ≥ 1.10 + 거래량 비율 ≥ 1.5 | 384 | 38 | 3.91% | 9.90% | 90.10% |

전체 발생률 12.32%보다 세 규칙의 정확도가 높지 않았다. 이 규칙들만으로 다음 날 윗꼬리 발생을 유용하게 경고한다고 볼 근거를 얻지 못했다. 오경보 비중은 FP/(TP+FP)이고 통계적 FPR=FP/(FP+TN)은 `summary.json`에 별도로 기록했다. 당일 고점 직전 경고 성능이나 급락까지 남은 분 단위 시간은 측정하지 않았다.

## 재현

```sh
python -m unittest discover -s experiments/reversal_warning -p 'test_*.py' -v
python experiments/reversal_warning/daily.py
# 원본 XML과 manifest.json을 results/에 복원한 뒤 인터넷 없이 재평가:
python experiments/reversal_warning/daily.py --from-cache
# 선택 사항: matplotlib 설치 환경에서 실제 캔들 이미지 생성
python experiments/reversal_warning/plot_shapes.py
```

원본 XML, SHA-256, 수집 시각, 제외 내역, 관측별 라벨·경고, 결과 JSON은 Actions artifact에 남는다. 과거 저장된 관측의 시점별 수정 이력은 없으므로 완전한 point-in-time 자료로 주장하지 않는다. 단일 출처이며, 상장폐지 종목 누락·수정주가·거래정지·수집 누락 위험을 전시장 검증에서 추가 점검해야 한다. 원본 유효가격·거래량 검사를 통과하지 못한 구간은 제외한다. 미완성 당일 봉도 통계에서 제외한다.

## 뉴스·공시 LLM 결합의 다음 검증 조건

이번 실행에서 뉴스·공시 LLM 성능은 시험하지 않았다. 당시 공개·수신된 원문 버전과 수집 시각이 필요하다. 공급계약, 자금조달·희석, 실적, 단순 테마 재탕 등 근거를 구조화하고 가격·거래량 모델과 동일한 기간에서 추가 기여도를 비교해야 한다. 현재 LLM은 과거 사건의 이후 전개를 학습했을 수 있어, 과거 기사만 입력했다고 시점누수가 제거되지는 않는다. 엄격한 성능 주장은 입력과 출력을 고정 저장하는 향후 관측 시험으로 확인해야 한다.

일봉 모양 확인은 완료했지만 원래 목표인 상승 중 장중 사전경고의 유효성은 아직 입증되지 않았다.
